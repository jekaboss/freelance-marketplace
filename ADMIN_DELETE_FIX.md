# Исправление удаления пользователя в админ-панели

## Проблема
Пользователи не могли удалить пользователей в админ-панели потому, что функции `handleDelete`, `handleDeleteAvatar` и `handleDeletePortfolio` возвращались рано при демо-режиме (админ-режиме).

## Решение
Переработал все функции удаления для поддержки демо-режима:

### 1. `handleDelete(id)` - Удаление пользователя
- **Демо-режим**: Удаляет пользователя из локального состояния
- **Реальный режим**: Отправляет DELETE запрос на `/users/{id}` и затем удаляет из состояния
- Добавлена обработка ошибок

### 2. `handleDeleteAvatar(userId)` - Удаление аватара
- **Демо-режим**: Удаляет аватар из локального состояния  
- **Реальный режим**: Отправляет DELETE запрос на `/users/{userId}/avatar`
- Добавлена обработка ошибок

### 3. `handleDeletePortfolio(userId, url)` - Удаление элемента портфолио
- **Демо-режим**: Удаляет элемент из локального состояния
- **Реальный режим**: Отправляет DELETE запрос на `/users/{userId}/portfolio?url={url}`
- Добавлена обработка ошибок

### 4. `handleToggleBlock(userId, currentlyBlocked)` - Блокировка пользователя
- **Демо-режим**: Обновляет статус локально
- **Реальный режим**: Отправляет PATCH запрос на `/users/{userId}/block`
- Добавлено оптимистичное обновление UI с откатом при ошибке

## Тестирование
Попробуйте удалить пользователя в админ-панели - теперь это должно работать в обоих режимах (демо и реальный).
